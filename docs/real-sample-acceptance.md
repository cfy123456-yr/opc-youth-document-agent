## 执行步骤

1. 复制 `samples/templates/manifest.example.csv` 中的格式，把样本登记到
   `samples/manifest.local.csv`。
2. 按 `samples/templates/baseline.example.json` 填写人工基线。
3. 运行 `python -m opc_agent samples validate`，修复清单和路径问题。
4. 运行 `python -m opc_agent samples eval`，生成
   `reports/real-sample-report.md` 和 `reports/real-sample-report.json`。
5. 人工复核所有禁止词命中、路由错误、缺失发现和高风险输出。
6. 把失败分为解析、路由、规则、模型、界面和数据格式六类。
7. 只修复高频且影响最大的失败，再建立 v0.3 回归集。

## 自动判定边界

批量评测可以自动判断：

- 文件能否被解析和处理。
- 自动路由是否符合人工预期。
- 必需字段或关键词是否出现。
- 预先定义的禁止词是否被生成。
- 人工指定标题是否被识别。

批量评测不能自动判断：

- 改写是否真正忠于原文。
- 合同风险是否在具体案例中成立。
- 票据金额是否与原件完全一致。
- 用户是否愿意采纳结果。

因此自动报告只用于筛查，决策门 C 仍要求逐份人工复核。
