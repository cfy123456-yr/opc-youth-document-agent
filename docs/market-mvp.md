# 市场 MVP 定义

## 首发用户

首次求职、实习和入职的中国青年。

## 首发问题

用户能够获得大量 AI 工具，但通常需要自己组织提示词、核对事实、复制结果，并承担隐私和错误风险。

## MVP 价值

把任务变成可完成的流程：

`上传 -> 解析 -> 分析 -> 用户确认 -> 导出`

## 模块成熟度

| 模块 | 成熟度 | 上线策略 |
| --- | --- | --- |
| 简历优化 | 首发 | 可直接测试 |
| 申请书函 | 首发 | 可直接测试 |
| 合同审阅 | 测试版 | 只做风险提示，必须人工复核 |
| 票据整理 | 测试版 | 先接收文本，再接 OCR |

## 成功指标

- 文档解析成功率
- 任务完成率
- 事实编造率
- 建议采纳率
- 用户是否导出结果
- 单任务耗时
- 单任务模型成本
- 是否再次使用

## 暂不建设

- 复杂多 Agent 协作
- 支付和订阅
- 企业审批流
- 大规模知识库
- 原生移动应用
- 自动替用户提交文件
